## 📝 Practice Strategy

For every topic, follow this cycle:

```text
Learn the concept
      ↓
Understand the syntax
      ↓
Run the examples
      ↓
Dry run manually
      ↓
Solve problems without looking at the solution
      ↓
Identify edge cases
      ↓
Write down tricky concepts
      ↓
Revise
```

### Before moving to the next topic

Make sure you can:

- Explain the concept in your own words
- Write the basic syntax without referring to notes
- Solve simple problems independently
- Dry run code on paper
- Identify common mistakes
- Handle basic edge cases

---

## 🎯 Important Principle

> **Don't memorize code. Understand the pattern behind the code.**

For example, while learning loops, focus on:

```text
What is changing?
What is the stopping condition?
How many times does the loop execute?
What happens in every iteration?
```

For arrays:

```text
What does each index represent?
What is the traversal direction?
What information do I need to maintain?
What is the time complexity?
```

The objective is to develop **problem-solving intuition**, not just Java syntax knowledge.
